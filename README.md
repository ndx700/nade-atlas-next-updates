# NadeAtlas Next updates

NadeAtlas Next 的独立公开 APK 更新渠道。这里保存安装包、更新清单、校验值及版本说明。

下载：请打开 [Releases](https://github.com/ndx700/nade-atlas-next-updates/releases/latest)，选择 standard（默认）、online 或 ultra。

首次手动安装 Next 0.20.1 后，后续版本可在应用内检查、下载并交由 Android 系统确认安装。同包名、同签名的 Next 更新可覆盖升级；Next 与原版可同时安装。

源代码保持私有。此仓库不保存签名私钥、发布令牌或 owner/AI 凭据。游戏资源的权利归相应权利人。
